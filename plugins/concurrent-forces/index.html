Concurrent Forces

MIDAS CIVIL NX · v1.3.0

🔒 Non-mutating Not connected

Nominate one key item and one result quantity — a member force, a plate force, a link force, a node reaction or a displacement. The plugin finds the load case, combination, stage and step at which that component governs there, and reports the forces in every other element of the set at that same structural state — the coexistent forces, not each element’s own independent extreme.

Endpoint MAPI key

CIVIL NX must be open, and the model analysed. A key keeps verifying after the program closes, so the live session is checked too.
