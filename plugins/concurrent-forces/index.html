🔒 Non-mutating Not connected

Nominate one key element and one force component. The plugin finds the load case, combination, stage and step at which that component governs there, and reports the forces in every other element of the set at that same structural state — the coexistent forces, not each element’s own independent extreme.

Endpoint Key —

CIVIL NX must be open, and the model analysed. A key keeps verifying after the program closes, so the live session is checked too.
