Target sizes are in the model’s own length unit, the same one /db/NODE reports coordinates in. A size of 0 means one division.

Write

Deleting a beam does not move the loads, supports or releases that reference it, and the plate mesh is not connected to the rest of the frame — joining them needs rigid links, which this plugin does not write. Leave the beams in place unless you have dealt with both.

Sections in the selection
